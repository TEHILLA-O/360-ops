# Licensing

No licence was verified, because no tenant was available.

| Capability | Typical requirement | This repository |
| --- | --- | --- |
| Power Automate cloud flows with Outlook, Approvals and Dataverse | Power Automate licence that includes those connectors, often seeded by a Microsoft 365 or Power Apps plan in a non-production environment | Specified, not created |
| Dataverse | Power Apps or a Dataverse-enabled environment | Specified. SQLite runs locally |
| Copilot Studio authoring | Copilot Studio user licence or trial | Authoring text is in the repo. The agent was not created |
| Copilot Studio Teams channel | A licence that allows publishing to Teams | Not published. Do not claim it is live |
| Microsoft Graph delegated calls | Entra app plus user consent or admin consent | Code is ready. No consent has been granted |
| Approvals connector | Included with many Power Automate plans and backed by Dataverse | Not used yet. Local simulation is labelled as such |

A Power Apps Developer Plan or a Copilot Studio trial does not by itself authorise production use or every publishing channel. Check the tenant's licence page before turning flows on.

The local Python service and the React UI do not consume a Power Platform licence.
